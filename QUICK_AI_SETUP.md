# Quick AI — repository status

**Status: NOT AVAILABLE in the current source tree.**

The current repository does not contain the native Quick AI overlay service, shortcut listener, Quick AI screen asset, or a working hosted AI API. The older setup steps in this document described planned functionality and are not valid installation instructions for the current build.

The current app provides its main local-first chat interface. Offline capabilities are limited to the bundled response catalogue and keyword-based retrieval from knowledge files imported by the user. It does not include a bundled local LLM or image-understanding model.

Do not grant overlay or Accessibility permissions based on this document. A future Quick AI implementation must include its actual Android service, UI, backend, permission rationale, and device-tested setup guide before being documented as available.
